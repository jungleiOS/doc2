# 好物决策卡模板

> 来源：从《AI 与淘客行业》一文提取的方法论（原文第七节第三步），适配知乎好物写作。
> 用法：每推荐一个商品，先在草稿阶段填完这张卡，写正文时只取其中最影响决策的 3-4 项，其余留作评论区答疑弹药。
> 原则：**填不出来的字段就是信息缺口，不要编，去查或者标注「未验证」。**

---

## 商品决策卡（复制以下区块填写）

### 商品：[品牌 + 具体型号]

| 字段 | 内容 | 信息来源 |
|------|------|---------|
| 实际到手价 | （当前价 / 大促价，注明查询日期） | |
| 历史价格 | （近半年最低价，可用比价工具查） | |
| 可用优惠 | （券、满减、有效期） | |
| 最适合的场景 | （给什么人、什么用途，具体到场景而非人群标签） | |
| **明确不适合谁** | （必填项：至少写一条，写不出来说明你对这个产品理解不够） | |
| 与同价位竞品的真实差异 | （不是参数罗列，是实际体验/定位差异） | |
| 常见售后与退货原因 | （差评区、客服记录里找） | |
| 真实用户反馈 | （自己实测 > 身边人反馈 > 评论区交叉验证，标注是哪一种） | |
| 佣金与利益关系 | （是否挂好物卡片、大致返佣比例——内部记录，正文不公开具体数字） | |

---

## 写作时的使用规则

1. **「不适合谁」必须出现在正文里**，这是和普通种草文拉开差距的核心字段。
2. 「最适合的场景」对应文章结构中的「先提问再推荐」：先帮读者确认场景，再给选择。
3. 「历史价格」和「售后原因」任选其一进正文，作为信息增量；都写会显得像评测报告。
4. 佣金字段只内部记录，正文不再写返佣/利益声明（2026-08-29 起）。
5. 一篇好物文推荐 2-4 个商品为宜，每个商品一张卡；超过 4 个说明场景没切细，该拆文章了。

---

## 选题判断（写文章之前先过这一关）

- 这个品类是「用户经常问到底怎么选」的品类吗？（决策难度高才值得写）
- 我能收集到真实用户问题吗？（评论区、私信、差评区，而不是 AI 编造）
- 这篇能替读者省掉「一小时的选择成本」吗？不能就不写。
