# 写作方法论

> 本项目通用的选题判断与结构判定方法，从根目录 AGENTS.md 下沉至此。各平台的具体结构模板、禁忌与质量清单以对应 Skill 为准。

## 选题与素材判断（HKR 模型）

- 判断问题/选题是否具备 **HKR** 至少两项：
  - **H (Happy)**：有趣、有悬念、让人想点开。
  - **K (Knowledge)**：有信息增量，看完能学到东西。
  - **R (Resonance)**：能戳中情绪或共鸣。
- 信息不足时，主动向用户追问：想讲哪几个点？有没有真实经历？最想吐槽或最兴奋的地方？

## 平台与结构判定

- 知乎：先判定问题类型（经验求助 / 观点讨论 / 知识科普 / 情感共鸣 / 盘点推荐），再匹配对应结构模板。
- 公众号：先判定文章原型（调查实验 / 产品体验 / 现象解读 / 工具分享 / 方法论分享），再按卡兹克风格组织。
