# 项目结构说明

> 本文档登记本仓库的目录树及各目录职责，供 Agent 快速了解文件归集结构。治理规则（目录命名、平铺约定等）以根目录 AGENTS.md 的 2.0–2.2 节为准。最后更新：2026-10-26。

项目采用 **话题 → 问题 → 文稿与资源** 的归集结构。每个话题一个目录，话题内每个问题一个子目录，问题目录里文稿和配图平铺（不分子目录），平台靠文件名前缀区分（`知乎回答-` / `zhihu-` / `百家号版-` / `公众号版-`）。话题目录按领域分组如下（平铺放在根目录，不再设分类层级）：

```
.
├── AGENTS.md
│
│  ── 话题归集目录（37 个，按领域分组） ──
│
│  【充电/配件】
├── 多口充电器选购指南/          # 充电器长文 + 主稿 + 30+ 衍生问题（本项目第一个话题，结构最完整）
├── 充电宝3C新规选购指南/        # 3C 新规长文 + 12 个衍生问题
```

## 话题目录内部结构（所有话题统一）

```
<话题>/
├── _主稿/          # 主稿文章 + 配图 + 截图脚本 + assets/（HTML 源 + cover-assets/ + raw/），无 _主稿 的话题从略
├── 问题对应表.md    # 话题级，登记所有问题的草稿文件、链接、发布状态（非强制，小话题可省）
├── 选题单.md        # 仅部分话题有
└── <问题名>/       # 每个衍生问题一个目录，文稿和配图平铺散放
    ├── 知乎回答-xxx-v1.md / zhihu-xxx-v1.md
    ├── 百家号版-xxx.md     # 有百家号版时才存在
    └── *.png / *.jpg / *.html / capture-*.js   # 配图、截图脚本、HTML 源，全部散放
```
