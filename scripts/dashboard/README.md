# 内容工作台看板

本地只读可视化服务，读 `data/zhihu.db`，不改任何数据。

## 启动

```bash
./scripts/dashboard/start.sh          # 启动并自动打开浏览器
node scripts/dashboard/server.mjs     # 只启动，手动访问 http://127.0.0.1:7788
node scripts/dashboard/server.mjs --port 8080   # 换端口
```

停止：在运行的终端按 `Ctrl+C`。

## 三个画面

| Tab | 回答什么问题 | 数据来源 |
|-----|--------------|----------|
| **回答表现** | 哪篇稿子真正转化了？高阅读低赞的是哪些？ | `answers` + `snapshots` |
| **选题池** | 1014 个候选里哪些是盲区？每轮为什么拒？ | `questions` + `question_decisions` |
| **互动关系** | 谁一直在赞我？还有多少人没回赞？ | `likers` + `liker_events` |

## 关键指标口径

- **赞阅比** = 赞同 ÷ 阅读。衡量「同样曝光换来多少认同」，比单看阅读量或赞同数更能定位问题。
- **高阅读低转化** = 阅读量高于中位数，但赞阅比低于全站平均值。这批稿子最值得复盘。
- **从未被评估** = 状态为候选、且没进过任何一轮 scout 打分的问题。
- **深度互动** = 累计赞过 6 次以上的人。

## 设计约束

- **不做时间折线**：快照只有 6 个采集日（间隔从 2 天到 40 天不等），连成折线是误导。全部用柱状、漏斗、占比表达。
- **按容器宽度建 viewBox**：SVG 1:1 渲染，避免半宽面板里字号被缩放拉小。
- **非激活 Tab 不参与布局**，切回来时按真实宽度重绘一次。
- **零外部依赖**：图表是手写 SVG，前端不引 CDN，断网可用。

## 文件

| 文件 | 作用 |
|------|------|
| `server.mjs` | HTTP 服务、API 路由、静态文件 |
| `queries.mjs` | 所有 SQL 与聚合，产出前端直接可用的 JSON |
| `public/index.html` | 三 Tab 骨架 |
| `public/app.js` | 拉数据、画图、交互 |
| `public/style.css` | 样式 |

## API

| 路径 | 内容 |
|------|------|
| `GET /api/meta` | 数据新鲜度与各表计数 |
| `GET /api/answers` | 127 篇回答 + 汇总分布 |
| `GET /api/answer-detail?url=...` | 单篇详情（快照历史、流量来源、同题对比） |
| `GET /api/pool` | 问题池状态、来源、决策、拒绝原因 |
| `GET /api/social` | 互动用户分布与待回赞清单 |
