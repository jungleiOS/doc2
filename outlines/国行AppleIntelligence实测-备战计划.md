# 国行 Apple Intelligence 实测 · 备战计划

> 目标：上线当天发用户视角实测，一周内发开发者视角实测，一篇引爆完成冷启动。
> 状态速查（2026-08-26 核实）：已完成网信办备案（7/15），库克财报会确认获批（7/30），官网千问扩展文档上线又撤回（8/8），iPhone 端尚未正式推送，传闻随 iOS 27 秋季推送。**现在是备战的最后窗口。**

## 0. 一句话策略

速度位抢不过媒体（爱范儿 3 月误开当天就出稿了），**我们抢的是「对照组」**：海外版 vs 国行 vs 国产 AI，同一批任务三组对比 + 开发者视角。对照组需要提前建好，这才是备战的核心。

## 1. 本周就启动的 5 件事

### 1.1 设备与账号对照组（零成本版 · 安卓主力修正版）
- [x] **前置确认**：Mac 为 M3 Max，支持 Apple 智能 ✅（2026-08-26 确认）——Mac 是第一被测机
- [ ] **定位修正**：主力机是 Android（5 年），无 iPhone 15 Pro+ 真机。内容钩子升级为「5 年安卓主力的 iOS 开发者实测国行 Apple 智能」——视角更稀缺，命中安卓/苹果摇摆人群
- [ ] **Mac 是第一被测机**：8/8 官网闪现的千问扩展文档明确「面向中国大陆 Mac 用户、macOS 26.6+」，Mac 端落地信号早于 iPhone 端；第一时间验证系统设置有无「Apple 智能与 Siri」
- [ ] **国产 AI 对照组就在自己 Android 主力机上跑**：豆包/千问/系统级 AI 是日常在用，对比是「我的日常 vs Apple 智能」，比纸上谈兵真实
- [ ] iPhone 端系统功能（Siri、写作工具、照片消除）：纯借不租，借港版/国行 15 Pro+ 两小时一次性采集；借不到则文献对照兜底
- [ ] 开发者篇不受影响：Foundation Models 在 Xcode 模拟器跑通（零成本，不依赖真机和海外账号）
- [ ] 录屏规范：统一壁纸、关闭无关通知、统一 1080p——对比图专业度全在这些细节里

### 1.2 统一测试 prompt 集（核心资产，现在建好）
同一批任务，三个对象各跑一遍：① 海外版 Apple Intelligence（现在就能跑）② 豆包 / 千问 / 文小言 App（随时能跑）③ 上线后的国行 Apple 智能。结果截图存档，就是文章骨架。

任务清单（每类 3-5 题，写到「测试集.xlsx」或备忘录）：
- [ ] **写作工具**：中文改写（正式/友好/简洁三档）、长文总结、故意写错别字的校对
- [ ] **Siri**：多轮上下文追问、屏幕内容感知、跨 App 操作（"把这张照片微信发给 xx"）
- [ ] **照片消除**：复杂背景路人消除，和 Google/小米消除对比
- [ ] **通知摘要**：微信群轰炸式通知的摘要质量（中文场景，AI 摘要最容易翻车的地方）
- [ ] **断网测试（杀手级）**：飞行模式下逐项过功能——哪些端侧可用、哪些必须联网，一目了然。这是「端侧隐私」叙事最硬的素材，全网很少有人系统做
- [ ] **可能缺席的功能逐一核对**：Genmoji、Image Playground、Visual Intelligence、ChatGPT 扩展——国行阉割清单本身就是流量选题

### 1.3 开发者弹药（现在就写代码）
Xcode 26 + iOS 26 SDK，Foundation Models framework 现在就能在海外设备/模拟器上跑：
- [ ] 写一个 demo App 覆盖：基础会话、流式输出、`@Generable` 结构化生成、Tool Calling、上下文窗口超限的降级处理
- [ ] 重点测**中文 prompt 表现**和**连续调用的限速/限额**——这是"普通用户能用到什么"的关键
- [ ] 代码片段和真机截图提前存好，开发者篇 70% 的素材来自这里

### 1.4 官方信源存档
- [ ] 截图存档 Apple 支持页（zh-cn/121115）、Foundation Models 官方文档当前版本
- [ ] 上线后对比文档变化，"文档改了什么"本身就是独家细节

### 1.5 文章骨架预制（上线前完成 70%）
- [ ] 用户篇骨架：两年跳票时间线（2024.9 预告 → 2025 多次传闻 → 2026.3 误开撤回 → 2026.7 备案 → 上线）+ 测试方法论 + 三组对照表，只留结果空位
- [ ] 开发者篇骨架：Foundation Models 是什么 → 国行实测数据 → demo 代码 → 对第三方 App 意味着什么（端侧模型免费调用 = 独立开发者零成本 AI 能力）

## 2. 上线当天（T 日）作战流程

1. 升级 + 开启流程全程录屏：设置入口位置、模型下载包大小、协议弹窗、备案信息页——这些是独有素材
2. 按测试集逐项跑，往预制骨架里填结果
3. 断网测试放在第一批跑，最容易出传播点
4. 当天晚 8 点前发用户篇，标题方向：「5 年安卓主力的 iOS 开发者，实测国行 Apple 智能第一天」
