先说结论，这事大概率不怪充电器，也不怪功率。

怪那根线。

先问一句，你连笔记本用的，是手机盒里那根原装线，还是随手抓的另外一根线？

你的答案，基本就是笔记本没反应的答案。

我研究充电协议这些日子，这类问题见得不少，十有八九出在线和握手环节，跟瓦数真没什么关系。下面掰开聊。

先说这颗头本身。很多人第一反应是，120W 的手机头充 65W 的笔记本，肯定是协议锁死了，功率放不出来。这话只对了一半。我手上没有这颗头，但[充电头网对它做过完整实测](https://www.chongdiantou.com/archives/1735875408923.html)，数据全是公开的，直接拉出来看。

这颗头是 USB-A 口，注意，是老式的 A 口，不是 C 口。实测下来，它会说两套话。

一套是小米自家的私房话，3.6-11V⎓6A 和 3.6-20V⎓6A 两组私有档位，120W 就靠这个触发，只伺候小米红米自家手机。

另一套是普通话，标准 PD 3.0，5V⎓3A、9V⎓3A、15V⎓3A，再加上一个 20V⎓3.25A。

![POWER-Z KM003C 实测，PD3.0 固定档含 20V⎓3.25A，红色字体是小米私有档位](./cover-assets/raw/k80pro充电头网评测/POWER-Z协议实测.jpg)

> 图源，充电头网《评测 REDMI K80 Pro 手机》，下同

看到最后那档没有。20V 乘 3.25A，正好 65W。

而你的笔记本要的，恰恰就是这档。也就是说，这颗头的菜单上明明写着 65W 这道菜，你的笔记本却愣是吃不上。

问题不在菜谱，在上菜的过程。

说到这个上菜过程，就得聊聊 PD 协议是怎么开始工作的。

设备插上充电器，不是直接通电的。双方得先对个话，充电器通过 C 口里一根专门负责对话的针脚，报出自己能提供哪些档位，笔记本挑一档，两边确认好了，才开始上高压大电流。这个对话，就叫握手。

握手没发生，充电器一滴电都不会给。

不是慢充，是零。

现在问题就来了。USB-A 是上一代接口，它天生就没有这根负责对话的针。。。

小米的解法挺取巧，在原装那根 6A 线上做魔改，线里塞了额外的触点和识别电路，配合 A 口上多出来的引脚，硬是把对话这条路修通了。所以这颗头的 PD 能力，一半在头里，一半在线里。

![K80 Pro 原装 A to C 线，A 口胶芯的橙红色是小米魔改线的辨识标志](./cover-assets/raw/k80pro充电头网评测/原装AtoC魔改线.jpg)

后果就来了。

你用原装线，握手有机会走通，65W 有可能点亮。你用任何一根普通的 A-to-C 线，线里根本没有这条对话通道，握手这条路是断的，笔记本那边干等不到回应，表现就是你看到的，完全没反应。

对了，这不是红米一家的毛病。前两年「华为 66W 原装套装充不了 iPhone 15」上过热搜，实测下来同一个剧本，A 口魔改头配不配套的线，握手归零。

接口长得像，不等于说的是同一种话。

那怎么办？两步，一分钟出结果。

第一步，换回手机盒里那根原装 6A 线，再连笔记本试试。能充了，谜底就是线，一分钱不用花。

第二步，原装线插上还是没反应，那说明你的笔记本不认 A 口转出来的 PD。确实存在这种挑食的机器，A 口魔改 PD 本来就是取巧方案，兼容性天生不如原生 C 口。这种情况别再折腾线了，几十块买个正经的 65W C 口 PD 氮化镓头，一步到位。

顺便教你一个以后都用得上的判断方法。看任何一颗充电器的铭牌或详情页，在输出参数里找有没有 20V⎓多少 A 这一行。绝大多数笔记本只吃 20V 这档，只有 5V/9V/12V 的头，哪怕标着 100W，也基本和笔记本无缘。个别机型能在低电压下慢充续命，但别指望正常用。

最后多说一句。这颗 120W 的头其实挺委屈的，它明明会说笔记本听得懂的普通话，只是这个技能被拆成了两半，一半在头里，一半在线里。

**功率决定上限，协议决定下限，而线材，决定你的设备之间到底能不能说上话。**
