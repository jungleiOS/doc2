# 多口充电器为什么一插多就掉速？功率分配原理 + 10 分钟验货清单

![封面：功率分配与验货清单](./知乎文章-功率分配与验货篇-封面.png)

充电头网的实测里有两个名场面：

- **一根「空线」偷走笔记本大半功率**：多口充电器上插着一根没接任何设备的苹果 Lightning 线，线头里的芯片会让充电器误判为多口同时输出，另一台设备的充电功率直接从满速掉到 9.66W。
- **原厂也翻车**：三星原厂 65W 2C1A 充电器，单口 65W 没问题，三口插满后的分配是 35W + 25W + 5W；两个 C 口各插一台笔记本，C2 口干脆停止输出。

问题都出在同一个地方：**功率分配**。这篇讲清楚两件事——多口同充为什么会掉速，以及下单前后怎么用一套 10 分钟的清单验掉九成的坑。

> 📚 本文是《多口充电器选购指南》系列文章之一。主文讲「按你的场景买什么」，本篇讲「多口同充的功率分配，以及怎么验货」。

## 一、多口同时用，功率分配是一门玄学

这是最容易被商家模糊处理的地方。

标称「100W 三口充电器」，单口用 C1 确实能到 100W。但一旦 C2 和 A 口也插上设备，很多产品的分配逻辑是**固定降档**——比如变成 45W + 30W + 15W，而你的笔记本可能刚好需要 65W 才能不掉电。

别觉得这只是杂牌的问题，开头三星原厂那个实测就是反例。连原厂都这样，白牌产品只会更离谱。

除了固定降档，还有评论区高频出现的两个翻车点，都是真实存在的物理现象：

- **空载的苹果线会「偷功率」**：就是开头那根线的实测——Lightning 线即使另一头什么都没接，线头芯片也会让充电器误判为多口输出，其他口的功率应声而落。多口充电器上用不到的苹果线，记得随手拔掉。
- **插第二根线时，第一台设备会「断一下电」**：充电头网在多款多口充电器的实测里都记录过这个现象，本质是充电器在重新协商功率分配，功率归零一两秒再恢复。大部分人无感，但如果你正在用笔记本开视频会议，这一下足够让人心头一紧。

更好的方案是选支持**动态功率分配**的产品，它会根据当前接入设备的实时需求智能调整：

- 单插笔记本 → 给满 100W
- 插上手机后 → 自动变成 65W + 30W
- 拔掉手机后 → 自动回升

怎么分辨真假动态分配？看两点：一是分配表，真动态分配会给多口输出写一个功率范围（比如 65W+30W～45W+45W），而不是每个组合一个死档位；二是看媒体实测，插拔设备后功率应该在几秒内自动回升，而不是断连或锁死在低档位。详情页只写「智能分配」四个字、分配表却全是固定档位的，基本是固定降档换了个说法。

这才是多口充电器的核心价值。

**记住：总功率是广告词，分配表才是合同条款。**

## 二、下单前，查三张表

原理讲完了，下面全是动作。下单前花 10 分钟查完这三张表，九成的坑都能提前避开。

### 1. 查单口输出规格表（防总功率虚标）

**去哪找**：商品详情页最底部的「规格参数」，或包装 / 铭牌照片。

**看什么**：找「单口输出」或「USB-C1 输出」那一栏，确认 C 口单独工作时的最大功率。你的笔记本需要 65W，那单口至少要写明 65W。

**红旗信号**：详情页通篇只有「140W 总功率」的大字海报，翻到底都找不到单口表——关掉页面，下一个。

### 2. 查多口功率分配（防断崖式降速）

**去哪找**：先看详情页有没有「多口同时输出」分配表；没有就搜「型号 + 多口输出」或「型号 + 充电头网」，看媒体实测的多口负载数据。

**看什么**：模拟你最常用的设备组合。比如「笔记本 + 手机」同插时，笔记本那个口还剩多少瓦？前文三星原厂 65W 三口插满只剩 35W + 25W + 5W 的实测就是参考系——连原厂都这样，小厂的表更要逐行核对。

**红旗信号**：分配表里出现「共享 15W」「合计 5V 档」这类字样，说明多口同插时必有设备坐牢。

### 3. 查协议列表原文（防文字游戏）

**去哪找**：参数页的「快充协议」一栏，认具体协议名，别看宣传图上的「快充」大字。

**合格线**：

- **苹果用户**：列表里必须有 **PD**（PD 3.0 / 3.1），「兼容苹果快充」不等于 PD；
- **三星用户**：必须有 **PPS**，且写有「3.3V-11V」这类可调电压范围；
- **华米 OV 用户**：认准「官方授权 / 官方认证」四个字，只写「兼容」的默认跑不满。

协议看不懂的话，先看同系列的[充电协议一篇讲透](https://zhuanlan.zhihu.com/p/2073203760332026596)，再回来对这张表。

## 三、收货后，做三个测试（用足 7 天无理由）

别急着点「确认收货」，趁退换期内做完这三件事：

1. **满载测试**：设备全插上，笔记本边用边充 20 分钟，看电量是涨是跌。跌，说明分配逻辑扛不住你的设备组合，退。
2. **插拔测试**：笔记本充着电，反复插拔第二根线。断一下电再恢复是正常的重新协商；反复断连、不再恢复，是质量问题，退。
3. **温度和「空线」测试**：满载半小时摸外壳，温热正常，烫到没法下手就退。顺手把充电器上**不用的线全部拔掉**——还记得开头那根空载苹果线偷功率的实测吗？

这套流程走完，商家海报上没写的，你全验过了。
