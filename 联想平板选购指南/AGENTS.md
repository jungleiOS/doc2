# AGENTS.md —— 联想平板选购指南

> 本目录沉淀《联想平板选购指南》及后续迭代的专属约定。任何 Agent 协助本目录前，先读此文件。

---

## 1. 这是做什么的

本目录是知乎长文《联想平板选购指南》及其衍生内容的归集区：

- `知乎文章-联想平板选购指南.md`：主稿。
- `商品分析.md`：每款商品的参数、卖点、适用/不适用人群原始分析。
- `assets/`：参数卡 HTML 源文件、截图脚本、生成后的单产品参数卡图片。
- `drafts/`：知乎回答草稿（如有）。

---

## 2. 数据源优先级（必须遵守）

写参数、做图、改文章时，按以下优先级采信：

1. **联想官方乐享知识库 / 联想官方商城配置信息页**（最高优先级）
   - 示例：`https://www.lenovo.com.cn/wiki/product-XXXXXX.html`
   - 示例：`https://m.lenovo.com.cn/wiki/product-XXXXXX.html`
2. **可信媒体/评测**：IT之家、什么值得买真实用户文、中关村在线用户点评、知乎真实体验、酷安。
3. **京东/苏宁详情页**：仅用于补充官网未标注的重量、尺寸、SKU 价格等。
4. **避免使用**：搜狐数码营销号、淘宝好物网、明显 AI 生成的电商水文。

**原则**：官网未公开的信息，必须写「官网未标注」或「由 XX 补充」，不能按营销话术脑补。

---

## 3. 产品图铁律

### 3.1 单产品单图

- **每款产品必须单独成图**，禁止把多款产品拼成一张「对比图」或「参数表大图」。
- 已提供脚本 `build-cards.js` + `capture-cards.js`，会自动为 `table-data.json` 里每个型号生成独立参数卡。

### 3.2 只用官方产品图

- 产品图优先使用联想官方素材（`lefile.cn` CDN 或联想官网产品页）。
- **禁止使用电商平台商品图、营销合成图、几合一渲染图**。
- 如果官网确实没有该型号的单产品官方图，宁可留白，也不拿电商图凑数。

### 3.3 图里放什么

- 图里只放：**官方产品图（或留白） + 产品名 + 副标题 + 价格 + 硬核参数**。
- 图里**不放**：优点、缺点、适合人群、不适合人群、用户评价、营销文案。
- 这些内容必须写在 `知乎文章-联想平板选购指南.md` 正文里。

---

## 4. 出图前工作流

**必须先给用户提供 Markdown 原始数据表确认，确认后再生成图片。**

标准流程：

1. 收集官方参数 + 全网真实评价。
2. 整理成 Markdown 表格（每款产品一张表），包含：官方图、处理器、屏幕、内存/存储、电池、重量、尺寸、价格、优点、缺点、适合人群、不适合人群、评价摘要、来源。
3. 等用户确认数据和修正点后，再执行：
   ```bash
   cd 联想平板选购指南/assets
   node build-cards.js
   node capture-cards.js
   ```
4. 用 `ReadMediaFile` 回看关键图片，确认无营销图、无错误参数后再交付。

## 5. 脚本说明

| 脚本 | 作用 | 何时运行 |
|---|---|---|
| `sync-prices.js` | 读取 `jd-products.json`，按品牌+型号匹配，把最新到手价同步到 `table-data.json` | 改了 `jd-products.json` 里的价格后 |
| `build-cards.js` | 读取 `table-data.json`，为每个型号生成独立 HTML 参数卡 | 改了参数/价格后 |
| `capture-cards.js` | 用 Puppeteer 把 `card-*.html` 截图成 `card-*.png` | 重新生成 HTML 后 |
| `fix-product-analysis.js` | 用 `table-data.json` 更新 `商品分析.md` 里的「官方参数」块 | 改了 `table-data.json` 后 |
| `build-tables.js` / `capture-tables.js` | 旧的多合一对比表（已不推荐使用） | 仅在用户明确要求多合一表时运行 |

**注意**：图片直接读的是 `table-data.json`，不是 `jd-products.json`。改了 `jd-products.json` 后必须先跑 `sync-prices.js`。

## 6. 文件命名

- 单产品 HTML：`card-<系列>-<型号>.html`
  - 示例：`card-entry-异能者-N10B.html`
- 单产品 PNG：`card-<系列>-<型号>.png`

## 7. 写作与修改原则

- **禁止 AI 味套话**：少说「不得不说」「总的来说」「毋庸置疑」；多写具体参数和真实用户反馈。
- **事实与推测分开**：官方参数写「来自联想官方乐享知识库」；推断写「按现有信息判断」「可能」。
- **最小修改**：只改与本次任务相关的型号和配图，不趁机重写全文、不删旧文件。
- **已发布/定稿谨慎**：如果 `知乎文章-联想平板选购指南.md` 已经发布或用户明确说定稿，修改前先征得同意。
- **来酷系列要克制推荐**：来酷是联想投资子品牌，官方参数透明度、真实口碑样本、售后预期均弱于小新/拯救者主线。推荐时必须把「为什么需要它」写清楚，不能当平价替代品强推。
