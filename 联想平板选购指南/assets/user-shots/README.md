## 图片命名建议

每个文件夹里的图片建议按场景命名，方便我后续自动插入：

```
<序号>-<场景>.jpg/png
```

示例：

- `01-real-usage.jpg` —— 用户实际使用场景（看网课、追剧、打游戏）
- `02-size-compare.jpg` —— 尺寸/重量对比（和手机、A4 纸、手掌对比）
- `03-handheld.jpg` —— 手持/单手握持效果
- `04-detail.jpg` —— 接口、按键、屏幕细节
- `05-package.jpg` —— 开箱/配件（键盘、笔、充电器）

如果你只找到一张图，直接放 `01-real-usage.jpg` 即可。

## 收集原则

1. **真实用户上传**：优先京东/淘宝带图评价、什么值得买晒单、酷安真实分享。
2. **避免营销图**：不要商品详情页、官方渲染图、达人摆拍商单图。
3. **隐私处理**：图片中出现人脸、快递单号、手机号、地址等敏感信息时，请先用系统预览打码或跳过。
4. **版权风险**：仅用于知乎文章内引用说明，不商用、不二次传播原图；如平台明确禁止转载，请跳过。
