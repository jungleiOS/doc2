# 临时图床上传（image-host-upload）

把稿件里的本地图片引用（`![alt](路径)` 与 `<img src="路径">`）批量上传到免费临时图床，替换为外链 URL，生成 `-hosted.md` 供直接粘贴进知乎/百家号编辑器。**不改动原稿。**

## 用法

```bash
node .agents/skills/image-host-upload/upload.js <文章.md> [--time 12h] [--force]
```

- `--time`：仅对链中 litterbox 生效（`1h`/`12h`/`24h`/`72h`，默认 `12h`），主图床 imgchr 无过期选项
- `--force`：忽略缓存全部重传
- 输出：`<原名去掉.md>-hosted.md`，与原稿同目录
- 退出码：全部成功 0，有失败 1（失败图保留本地路径引用并在结尾列清单）

## 工作原理

1. 解析文中本地图片引用（含 `./`、`../` 相对路径，`%20` 自动解码；跳过已是 `http(s)://` 或 `data:` 的引用；同一文件去重）
2. 查缓存：项目根目录 `.image-host-cache.json`，key 为 `绝对路径::文件大小::mtimeMs`。命中则不重复上传
3. 未命中则并发 3 个上传图床，成功后替换文中引用
4. 终端打印清单表（序号 | 本地路径 | 图床URL | 过期时间）与汇总行：`共 N 张，上传 M 张，命中缓存 K 张`

## 图床链（按顺序依次尝试，第一个成功即止）

| 优先级 | 图床 | 特点 | 2026-09-15 实测 |
|--------|------|------|-----------------|
| 主 | imgchr.com（路过图床） | 国内、免注册、无防盗链；需先抓首页 auth_token+Cookie（脚本自动处理）；同 md5 拒绝重复上传；**匿名限 8 张/天**，超出自动回退兜底图床；官方无过期声明（仍当临时用） | **可用**，当前实际生效图床 |
| 兜底 | uguu.se | 境外，免注册，约 3h 过期 | 可用 |
| 兜底 2 | litterbox.catbox.moe | 境外，`--time` 控制 1-72h 过期 | 本网络返回 HTTP 500，不可用 |
| 兜底 3 | tmpfiles.org | 境外，免注册，1h 过期，返回 JSON 需转 `/dl/` 直链 | 本网络连接被重置，不可用 |

> 图床可用性随网络环境变化，上传时会自动按链回退。曾测试放弃的国内候选：SM.MS（服务迁移中，302）、z4a.net（证书失效）、imgurl.org/imgse.com（已弃用跳 imgchr.com）。若未来境外图床恢复可用，脚本自动兜底，无需改代码。

## 核心纪律：缓存即溯源凭据

`.image-host-cache.json` **永久保留、不要删**。它记录每张图的 `本地绝对路径 -> 图床URL` 映射。图床过期后，凭缓存可以立刻定位本地原图（key 含绝对路径）；同一文件（大小+mtime 未变）再次发布时直接命中缓存，零上传。

## 调用协议（供其他 Skill 使用）

zhihu-answer-drafter 等 Skill 在配图完成、定稿待发布后执行：

```bash
node .agents/skills/image-host-upload/upload.js <稿件路径>
```

把生成的 `-hosted.md` 交给用户粘贴进平台编辑器。

## 注意事项

- **图床仅几小时有效**：发布后要确认平台已把图片转存到自家服务器（重新打开文章逐图检查）。知乎对纯外链图可能拦截或不显示，必须以发布后实际显示为准
- 若发布时发现外链图挂掉，用缓存里的本地路径找到原图，重新跑一次 `upload.js --force` 换新 URL 重贴
- `-hosted.md` 是临时产物，平台转存确认无误后可删除；原稿永不改动
- 单张失败不中断整体，退出码 1 表示有失败图需人工处理

## 前置条件

- Node.js 18+（零 npm 依赖，仅用内置 `fetch`/`FormData`/`Blob`）
- 文中引用的本地图片必须真实存在（相对路径以稿件所在目录解析）
