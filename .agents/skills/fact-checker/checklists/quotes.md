# 引用/转述类声明核查清单

对 Q 类声明逐项过：

1. **信源真实存在**：报告/文章/言论是否真实存在？找到原始出处。
2. **转述忠实度**：对照原文关键句——
   - 数字是否一致？
   - 是否截断语境（原文是限定条件下的说法，稿中转述成普遍结论）？
   - 是否把「某高管在某种场合说的」写成官方立场？
   - 直接引语加引号的部分，逐字与原文比对。
3. **人名/头衔/机构名**：逐字核对，包括公司名变更（旧名新名混用是常见错误）。
4. **时间归属**：引言的原始发表时间是什么？写成「近日/最近」是否已过期？
5. **引用链**：如果稿中引用的是二手转述（「据XX媒体报道，IDC称……」），回溯到 IDC 原文核实，不能只核中间层。
