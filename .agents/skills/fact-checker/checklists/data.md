# 数据类声明核查清单

对每个数据声明（D 类）逐项过：

1. **存在性**：外部信源里能查到这个数字吗？查不到 → ❓。
2. **口径**：同比还是环比？按销量还是销售额？出货量还是激活量？含税还是不含税？口径与信源不符 → ⚠️ 或 ❌。
3. **单位**：mAh / Wh / W / V 换算对不对？中文语境「度电」「毫安」混用是最常见错误。
4. **时间点**：数据所属期间是什么？稿中是否加了正确的时限词（「2025年」「Q3」）？
5. **四舍五入**：稿中数字是否夸大了精度或幅度（信源 28.6% 写成「接近35%」）？
6. **内部自洽**：
   - 分项之和 = 总数？
   - 前文用的参数，后文推算时是否换了一个数？
   - 百分比是否全部基于同一分母？
   - 时间推算对不对（充电时长 = 容量/功率的粗算是否合理）？
7. **AI 幻觉模式优先扫**：
   - 一位小数的百分比（37.2%、58.4%）——LLM 最爱编；
   - 精确到个位的价格/销量（售价 3299 元、卖出 127 万台）；
   - 不存在的型号名、规格名（和官方命名规范对比）；
   - 「据XX报道」后面跟的信源是否真实存在。
