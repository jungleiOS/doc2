# 因果/对比/结论类声明核查清单

对 C 类声明逐项过：

1. **结论强度匹配**：
   - 「可能/大概率」被写成「必然/一定」？
   - 「相关」被写成「导致」（相关≠因果）？
   - 「在某些条件下成立」被写成无条件成立？
2. **因果链完整性**：A→B 的推理中，中间环节是否被省略？省略后是否构成错误归因（单因果解释多因素现象）？
3. **对比公平性**：
   - 比较双方条件是否对等（同价位？同时间段？同口径）？
   - 是否只选了对自己结论有利的样本？
   - 「碾压/吊打/全面超越」类词是否有数据支撑，还是纯修辞？
4. **反例测试**：主动找一个削弱该结论的反例或例外。找不到明显反例才放行。
5. **观点伪装事实**：以陈述句出现的主观判断（「所有人都知道」「明眼人都看得出来」），标出并建议改写成明确的观点句或删掉。
6. **预测类断言**：「未来一定会」「明年将」——标记为不可证实（❓），建议软化或注明依据。

## 反向核查要求

对每个主要结论，额外回答：「读者/评论区最可能拿什么反驳？」列出 1-3 条文章未覆盖的反面事实或口径限定，写入报告的「反向核查清单」。这部分不判对错，只补盲区。
