# 审校报告模板

文件名：`审校报告-<原稿名>.md`，放在被审文稿同目录。

```markdown
# 审校报告：<原稿文件名>

- 审校日期：<YYYY-MM-DD>
- 核查范围：数据 D1–Dn（100%）| 事实 F1–Fn（100%）| 因果/对比 C1–Cn（100%）| 引用 Q1–Qn（100%）| 低危项（仅列清单）
- 总评：<一句话：能否发布 / 修高危后可发布 / 需大修>

## 🔴 高危速览

| 编号 | 位置 | 问题 | 判定 | 一句话建议 |
|---|---|---|---|---|

## 逐条明细

### D1. 「<原文原句>」（<章节名>）
- 信源：<URL>（<发布时间>）
- 原文关键句：「……」
- 差异：<口径/数字/时间点差异，无则写「无」>
- 判定：✅ / ⚠️ / ❓ / ❌ / 🔴
- 建议：<具体修改建议；❓ 项给「改标据公开资料」或「删除」两选>

（F/C/Q 同格式）

## 反向核查清单（文章未覆盖但读者可能质疑的点）

1. <反面事实/口径限定/漏掉的竞品或新规>

## 立场一致性检查

- 同话题已发布内容：<有无矛盾，列文件路径>
- 结论：<一致 / 矛盾点>

## 低危项清单（未核查，仅列示）

- <常识/观点类声明列表>

## 误报记录（作者仲裁时填写）

| 编号 | 作者判定 | 说明 |
|---|---|---|
| | 采纳 / 误报 | |

## 可入事实库

| 事实 | 来源 | 核查日期 |
|---|---|---|
```
