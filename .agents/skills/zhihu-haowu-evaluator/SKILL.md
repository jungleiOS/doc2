# 知乎好物评估（zhihu-haowu-evaluator）

判断一篇知乎内容插好物卡片的期望收益与风险，输出三档结论。核心红线：**用户没有真实使用/实测过的商品，一律不推**（遵守根 AGENTS.md 不编造原则）。

## 收益模型

好物期望收益 = 流量 × 购买意图 × 选品供给，乘法关系，任一因子为零则不值得插。

### 前置检查：账号权限

好物推荐的开通门槛知乎多次调整（Lv3/Lv4/Lv5 都曾是官方口径，基础权限与扩展权限分级），**不凭记忆写死门槛**。

已知状态：2026-08-24 用户确认创作等级 **Lv8**，超过所有历史门槛口径，好物权限（含扩展权限）视为已具备。仍有两个例外要留意：违规会被收回权限（此时结论降级为「不插」并提醒用户查通知）；平台若再调规则，以用户在创作中心看到的状态为准。

### 因子 T：流量

- 选题场景：直接复用问题数据快照（关注/浏览/回答数），沿用 scout 的 D 分档即可。
- 老回答回填场景：看自己回答的赞数、问题下排名、问题浏览量。自己回答排在 5 名开外且赞数个位数，流量因子按近零处理。

### 因子 B：购买意图（核心因子）

- 高意图信号：标题含「求推荐 / 怎么选 / 哪个好 / 值得买吗 / 预算 X / 有没有 X」；问题描述里出现预算、使用场景、在几个型号间纠结。
- 低意图信号：机制科普（「为什么」「是什么原理」）、观点讨论、情感共鸣类。这类题插卡会强化软文感、损害回答可信度，结论默认「不插」。
- 擦边情况（如「XX 是不是智商税」）：看正文落点，落到选购建议才可插。

### 因子 S：选品供给

- 用户是否有真实使用/实测过的对应商品：没有 → 一票否决，直接「不插」。
- 有实测商品时，确认该商品在好物库可挂（京东/淘宝/知乎商品），估一下价格带与佣金的量级即可，不精确算钱。
- 卡的商品必须与正文实测的是同一款，禁止正文写 A、挂卡挂 B。

## 输出结论（三档）

```markdown
- 好物评估：推荐插（商品方向：xxx；建议位置：实测段落后）/ 可插不优先（原因）/ 不插（原因）
```

## 插入建议（结论为「推荐插」时给出）

- 卡放在实测段落之后或文末，不放开头——先建立信任再给购买入口。
- 一篇回答 1-2 张卡，不堆卡。
- 正文必须有与商品对应的真实体验描述，空挂卡等于广告贴，有限流风险。
- 确定选品后，起草时按仓库根目录 `references/好物决策卡模板.md` 逐品填卡（「不适合谁」必填；填不出来的字段就是信息缺口，去查或标注「未验证」，不要编）。

## 两个调用场景

- **A. 选题精评（被 scout 调用）**：输入问题标题 + 描述 + 数据快照，输出一行三档结论，由 scout 写进选题单。不进 D×O×M 总分（好物是变现维度，不是流量维度），总分并列时优先「推荐插」的题。
- **B. 老回答回填（独立触发）**：输入回答文件路径 + 对应问题数据，评估值不值得回填好物并给出选品方向。

## 禁忌

- 不凭记忆断言好物权限门槛，以创作中心实时状态为准。
- 不给无真实体验的商品开绿灯，「这个品看起来很火」不是供给。
- 低购买意图的题不为了佣金硬插，可信度损失大于佣金收益。
