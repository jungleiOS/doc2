# 知乎带货回答起草助手（zhihu-haowu-drafter）

把 zhihu-haowu-scout 确认要答的带货问题写成回答初稿，并在成稿中完成好物选品与插卡。问题级好物评估（这题值不值得插、三档结论、插卡时机）在 **zhihu-haowu-scout** 选题阶段已完成，本 skill 直接复用其结论，不重复评估。

## 公共流程

浏览器通道检查、读问题完整描述（含逐点回应/指代纪律/不编造台词/修辞字面语法/术语门槛）、事实核查与迭代改稿流、配图工作流、去 AI 味、立场句标注兜底、数据校验、GEO、存档登记，全部与 **zhihu-answer-drafter** 共用，见 **[../zhihu-answer-drafter/drafter-common.md](../zhihu-answer-drafter/drafter-common.md)**（锚点：§1 浏览器通道检查 / §2 读问题完整描述 / §3 事实核查与迭代改稿流 / §4 配图工作流 / §5 去 AI 味 / §5.5 立场句标注兜底 / §5.7 校验数据准确性 / §6 GEO/SEO 审查 / §7 存档与登记），本文件不再重复。

## 决策卡变体（带货主轴）

决策卡的交付方式、仲裁机制（普通文字消息、逐项「认/不认 + 一句理由」、禁用 AskUserQuestion、作者未回复前不得动笔）与 zhihu-answer-drafter 完全相同，见该 skill 决策卡一节。维度上做两处调整：

- **立场候选降次**：带货题多数为选购/经验求助题，立场分歧小——立场候选不再单列维度，并入战场分析与素材复用判断；确遇观点分歧的带货题再临时补。
- **带货适配三要素升为主轴**〔agent 产，作者裁〕：
  1. **读者决策时刻远近**：「哪个好」=明天就下单，转化高；「该不该买」=还在纠结，转化低；
  2. **选品方向**：结合正文实测素材与好物库可挂性，给出 1-2 个候选商品方向（选品红线见下文商品级好物工作）；
  3. **预计插卡位置**：结合骨架段落安排，预估卡落在哪个段落之后（插卡位置原则见下文）。
  
  其余维度（战场分析 / 流量类型 / 人设影响 / 时效等级）照常。观点题里硬插商品卡 = 读者立刻识别软文 = 毁人设，须在决策卡中明确标注风险。

## 骨架（占位，待补）

带货稿骨架作者暂未定稿，不设预设模板（不预设「需求拆解→对比→推荐」式结构）。每篇骨架由作者在决策卡/改写意见中逐篇仲裁，随实战在本节沉淀。

## 商品级好物工作（2026-10-22 并入自原 zhihu-haowu-evaluator）

问题级评估（收益模型、流量/购买意图因子、三档结论）归属 **zhihu-haowu-scout**，不在本 skill。本节只管商品级：选品、好物库可挂性、卡的商品与正文同款、插入位置与话术。

### 选品（核心红线）

**用户没有真实使用/实测过的商品，一律不推**（遵守根 AGENTS.md 不编造原则）。

- 有实测商品时，确认该商品在好物库可挂（京东/淘宝/知乎商品），估一下价格带与佣金的量级即可，不精确算钱。
- 好物推荐的开通门槛知乎多次调整，**不凭记忆写死门槛**。已知状态：2026-08-24 用户确认创作等级 Lv8，好物权限（含扩展权限）视为已具备；例外：违规会被收回权限（此时插卡结论降级为「不插」并提醒用户查通知）；平台若再调规则，以用户在创作中心看到的状态为准。
- 「这个品看起来很火」不是供给，不给无真实体验的商品开绿灯。

### 对比维度

正文涉及多商品对比时，对比维度从实测素材中提炼（价格带、核心规格、实测数据、适用人群边界），**卡的商品必须与正文实测的是同一款，禁止正文写 A、挂卡挂 B**。

### 好物卡插入位置与话术

- 卡放在实测段落之后或文末，不放开头——先建立信任再给购买入口。
- 一篇回答 1-2 张卡，不堆卡。
- 正文必须有与商品对应的真实体验描述，空挂卡等于广告贴，有限流风险。
- 插卡话术跟随段落自然带出（实测结论句之后），不另起广告腔段落；话术本身过一遍 drafter-common §5 的句级 AI 腔检查。
- 确定选品后，起草时按仓库根目录 `references/好物决策卡模板.md` 逐品填卡（「不适合谁」必填；填不出来的字段就是信息缺口，去查或标注「未验证」，不要编）。

### 插卡时机（执行侧）

延迟插卡冷启动规则（48h 默认、仅强购买意图题首发直插）以 **zhihu-haowu-scout** 第 5.5 节为唯一出处，本 skill 只按选题单结论执行，不在此复述。

### 老回答回填好物（独立场景）

输入回答文件路径 + 对应问题数据，评估值不值得回填好物并给出选品方向。此场景下先判断「值不值得插」（复用 haowu-scout 的问题级口径），再按本节商品级流程执行选品与插卡。

## 禁忌

- 不替用户实际提交/发布任何回答或商品卡，绝不点发布按钮。
- 不给无真实体验的商品开绿灯；卡的商品与正文实测必须同款。
- 低购买意图的题不为了佣金硬插，可信度损失大于佣金收益。
- 不凭记忆断言好物权限门槛，以创作中心实时状态为准。
- 其余红线（读问题完整描述、事实核查、配图、去 AI 味）见 drafter-common 对应节。
