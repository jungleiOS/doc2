# 如何看待千问将推出Personal Agent，AI真的能帮人干活了？

前排答案都在转同一个故事：阿里巴巴千问即将发布的个人AI助手「千问Go」，帮测试用户要回了 70 块航班延误现金赔偿、52 块淘宝价保差价。细节很生动，航司客服先给代金券，它坚持交涉，最后钱进了支付宝。

我想问一个扫兴的问题：**它替你做 10 单这样的业务，有几单做成了？**

<!-- 判断句 -->
所谓 Personal Agent（个人AI助手），简单说就是你下一句话，它替你打开 App、登录账号、找入口、跟客服交涉，把事办完。能演示这件事，和能量产这件事，中间差着一个数量级。而且截至今天（2026-10-13），千问Go 还没有正式上线，所有报道的口径都是「即将发布」——我们讨论的其实是一个连公测都没开始的产品。

![千问Go-产品界面实拍.jpg](https://h.uguu.se/qisKHvnK.jpg)

*图源：硬AI（搜狐转载），千问Go 内测界面实拍，「试一试」入口里就有价保、航班延误沟通赔偿*

先把那两个案例的成色说清楚。70 块和 52 块的出处，是媒体转述的「测试用户分享」：[澎湃新闻](https://m.sohu.com/a/1087098371_260616)、[IT之家](https://m.sohu.com/a/1087078404_114760)、[硬AI](https://www.163.com/dy/article/L94EP9CI053144S4.html)引的是同一批材料，没有一家独立复现过。内测环境是什么？厂商精选的顺手的题目，全程有人盯着，跑不通可以人工兜底。真实世界是脏数据、奇葩页面、客服扯皮和用户自己都不记得的订单。这两件事的难度差距，打个比方：发布会上自动驾驶演示零接管，和早高峰五环上零接管。

![千问Go-70元航班延误赔偿案例.png](https://n.uguu.se/pkcAQQvV.png)

![千问Go-52元淘宝价保退款案例.jpg](https://h.uguu.se/NXoqYKoP.jpg)

*图源：硬AI 报道引用的测试用户分享截图（2026-10-12）——两张图就是目前「AI 能干活」的全部公开证据*

再看整个行业的家底。阿里云自己发过一份《2026 Agent 开发者调研报告》（有效问卷 1906 份）：[任务成功率能做到 90% 以上的企业只有约一成，16% 的企业压根没量化过成功率](https://github.com/aliyun/ai-agent-handbook/blob/main/2026-agent-survey-report.md)。<!-- 判断句 -->

更直观的是一个叫 OSWorld 的考试。这个测试由新加坡国立大学等高校的研究团队推出，考法跟千问Go声称要干的事几乎一样：给 AI 一台装着真实操作系统的电脑和 369 个日常任务——用 Chrome 查资料、用 LibreOffice 做表格、用 GIMP 修图、管理邮件——不告诉它点哪里、按哪个键，只交代目标，最后按「任务完成率」打分。这不是问答，是真刀真枪操作电脑，所以被视为桌面 Agent 领域最硬的一张成绩单。

成绩是这样的：人类参考成绩 72.36%；[公开榜单第一名 Agent S3 是 63.5%](https://www.codesota.com/benchmark/osworld)；[OpenAI 的 Operator 独立评测只有 32.6%，官方自报 38.1%](https://realtime-ai.chat/posts/computer-use-agents/)——同一家的分数，自己和别人测出来差 5 个百分点，本身也说明这类成绩对环境很敏感。

翻译成人话：现在全世界最能干的电脑操作 Agent，干活大概做三次挂一次；OpenAI 的，做三次挂两次。<!-- 判断句 -->而同一批模型在聊天对话类榜单上动辄 90 分上下——聊天和办事，根本是两张成绩单。

![阿里云Agent调研-三城Agent开发状态分布.png](https://h.uguu.se/JdvxlhXx.png)

*图源：阿里云《2026 Agent 开发者调研报告》图 1——报告正文结论：Agent「真正部署到生产环节的只有 18%」，量产是少数派*

聊天的时候你会觉得它什么都会，是因为聊天的容错率高——答错了你追问一句就行。替人办事的容错率低得多：价保找错订单、索赔材料传错，损失是实打实的。<!-- 判断句 -->

还有一层前排没人提的：授权。

它要替你干活，就得拿着你的账号登录淘宝、登录机票平台，凭证存在它的云端。这在业内是有共识的风险——高风险动作（转账、删除、发邮件）必须人来点最终确认，也就是所谓 HITL（human-in-the-loop，关键一步留给人工把关）。<!-- 判断句 -->

问题就在这：如果每一步关键操作都要你盯着点确认，它替你省下的时间还剩多少？<!-- 判断句 -->还有一个更隐蔽的麻烦叫提示注入——别人在网页或商品描述里埋一句专门给 AI 看的指令，你的助手读到就可能照做。这在 [Agent 安全圈已经是公开的攻击套路](https://www.secrss.com/articles/88564)。

那大厂为什么扎堆？这个问题描述自己把答案写了：依托「AI模型与核心交易平台的双重优势」，「覆盖从需求到订单的完整链路，进一步提升其生态内的交易转化率」。

翻译一下：帮你干活是路径，让你留在它的生态里下单才是目的。<!-- 判断句 -->

这不是黑阿里，全世界都在抢同一个位置。OpenAI 的 [ChatGPT Work](https://openai.com/index/introducing-chatgpt-agent/)（2026 年 7 月上线）、字节的 Coze Space、腾讯的 WorkBuddy、Manus 2.0（[10 月拿了超 5 亿美元融资回归中国市场](https://www.cls.cn/detail/2243572)），全在「Personal Agent」这个赛道里。抢的是「需求的入口」——以前你在淘宝搜，现在你直接跟助手说，谁握住这句话，谁握住整条交易链。<!-- 判断句 -->

可能有人要说了：产品还没上线你就泼冷水，是不是见不得国产好？

我泼的不是千问一家的水。OpenAI 自家操作电脑的 Operator，在 OSWorld 上的成绩也只有 [32.6% 到 38.1%](https://realtime-ai.chat/posts/computer-use-agents/)，全世界的 Agent 都在同一片泥地里爬坡。<!-- 判断句 -->「未上线先刷屏」本身就值得警惕——发布即巅峰的产品，这两年大家见得还少吗。

回答标题最后一问：AI 现在真能帮人干活了吗？

能，但要划好边界。<!-- 判断句 -->

现在就能交给它的：低风险、可逆、办砸了最多损失点时间的重复交涉——价保、发票、延误索赔这类，而且要你能随时接管、随时叫停。<!-- 判断句 -->

现在别碰的：一切「错了撤不回来」的事。转账、医疗、法律文件，以及任何你没亲眼看到它每一步操作的账号。<!-- 判断句 -->

AI 现在更像一个手脚麻利、但需要你在旁边盯着的新员工，还不是一个可以放心出差的老员工。等它不再需要你在旁边盯着的那天，「AI 能不能干活」这题才真的有答案——现在下结论的，不管看多还是看空，都是在赌。
