# 如何评价 Kimi K3.1？能否重燃国模荣光？

发布两天，舆论基本分成两派。打开评论区，一边是「十分钟烧光整段额度」的账单截图，另一边是「SOTA 级别就够了」的榜单转发。

这两拨人其实没吵在同一个东西上。骂账单的不一定否认能力，夸能力的也没解决账单。

先把我的结论放这：单论模型能力，K3.1 Pro 已经站进全球第一梯队，这个结论有第三方独立证据撑着，不靠月之暗面自己念稿；现在真正的争议在额度，而额度墙是整个长程 Agent 品类的结构性矛盾，不是 Kimi 一家的问题。「国模荣光」能不能重燃，模型这关过了，还差权重落地和额度算账方式两关。

## 能力这关：看第三方，别看发布会

国产模型发布，第一件事是分清哪些数字是厂商自己报的、哪些是第三方独立测的，这次也一样。

最硬的一条来自评测机构 Artificial Analysis。K3.1 Pro 的智能指数（AA 把多项基准加权算出来的综合分）55 分，全球第四，前面只剩 Claude Opus 5.5（58）、Claude Sonnet 5.5（56）和还没开放 API 的 Meta Muse Wonder Full（56），GPT-6 Astra 和 Gemini 4 Argon 都被压在后面，两家都是 53。上一代 K3 是 44 分，一次涨了 11 分。榜单归榜单，但这是[发布当天就出的独立评分](https://post.smzdm.com/p/aqrqvmmp/)，不是厂商 PPT。

![02-ArtificialAnalysis智能指数榜-知乎专栏.jpg](https://s41.ax1x.com/2026/10/25/pnDO9Pg.png)

*图源：知乎专栏 AI信息Gap 实测文，Artificial Analysis Intelligence Index v4.3.2 榜单截图*

这轮争论里反复出现一个数字：官方口径下 K3.1 Pro 比 Opus 5.5 差 0.7 分。这个数字得拆开看。

Terminal-Bench 4.0 上，Kimi 官方口径是 65.7%，Opus 5.5 是 66.4%，差 0.7；同一项测试，Artificial Analysis 独立跑出 67.2%，全场第一。但注意，AA 那一轮里 Opus 5.5 只跑出 59.6，比官方表里的 66.4 差了将近 7 分——两边的评测环境（harness）和思考强度设置根本不同，数字不能直接搬来比。

所以差 0.7 和反超都不构成「谁碾压谁」，能构成的结论只有一个：**终端编程这件事上，它已经进了第一梯队的讨论范围**，而半年前 K3 在这项测试上只有 12.6%。

![01-官方基准总览-IT之家.png](https://s41.ax1x.com/2026/10/25/pnDOCGQ.png)

*图源：IT之家转月之暗面官方基准成绩总览（厂商自报口径）*

账本也好看了。Artificial Analysis 按整轮评测算单任务成本：K3.1 Pro 平均一个任务约 1.98 美元，Claude Opus 5.5 是 5.98 美元，GPT-6 Astra 是 3.26 美元。

成本优势一半来自降价，另一半来自它的一个怪癖：话多。

跑完一整套评测，它输出了约 1.5 亿 token，比参评模型中位数（8700 万）高出七成。单看这个数字像缺点，但 API 单价降到上一代的三分之二（输入 13 元、输出 68 元每百万 token）。话多却按便宜单价计费，总账反而省了。

![backup-TerminalBench成本图-IT之家.png](https://s41.ax1x.com/2026/10/25/pnDOLYF.png)

*图源：IT之家转 Terminal-Bench 4.0 分数-成本分布，K3.1 Pro 在高分档里成本最低*

「话多」和「任务贵」是两码事，这是看跑分新闻最容易混掉的一组概念。

## 额度争议：该骂的是套餐，不是模型

再说骂声最大的额度。[多家媒体汇总的社区实测](http://www.36kr.com/p/4039236862514306)里传播最广的一个案例：99 美元套餐跑了约 47 分钟，就触发了 5 小时额度限制。

类似的还有：19 美元档一个任务烧掉整段额度；B 站那位复刻 GTA 风格视频的兄弟花了 10 小时、400 万 token、近 52 美元——按 API 价自费，绕开套餐反而划算。

这事得骂，但骂准对象。反证不难找：Claude 阵营同样能搜到一大堆撞额度墙的社区反馈，20 美元档一个复杂 Prompt 耗尽 5 小时额度的抱怨，在它家早就不是新闻。

额度焦虑是长程 Agent 这个品类的结构性矛盾——模型越会自己搜索、调工具、自我检查，单任务就越长，烧光推理预算就越快，而套餐上限的调整速度追不上模型能力的上涨速度。

这道墙是这个品类共有的，只是 Kimi 第一个撞上去，声音最大。

所以对额度问题，我的态度是：骂套餐细则不透明是对的，借额度问题推导出「模型不行」是偷换。

## 难听的也摆在这

立场摆这了，缺点也得说足，不然这篇就成软广了。

先交代一句：我说「第一梯队」，指的是 Agent 和代码这个主战场，不是全项追平。下面这些缺点，恰恰是限定这个结论的边界。

**它偏科。** 提升最大的是 Agent、代码、3D 这类长程带工具的任务；知识类的提升幅度没这么一致，科学推理还明显落后（Terminal-Bench Science 38.1，同期 Astra 68.1，官方口径）。所以「全面追平最强闭源」这个说法，目前没有任何官方或第三方依据。

**它比 Opus 慢。** 输出速度约 80 tokens/s（AA 页面从首测的 73.5 一路刷新上来），仍低于同价位中位的 81。日常轻量问答用它不划算，它真正的主场是长任务。

**宣发话术要打折。**「价格是 GPT-6 Astra 的五分之一」对应的是单价叙事，任务级成本优势大约四成，没有 80% 那么夸张；「幻觉率降到 8.3%」是官方内部基准、专挑易错场景的压力测试口径，而且同一测试里 GPT-6 Astra 是 5.5%，它并非最低。

「最强开源模型」眼下还是将来时——完整权重承诺 11 月 4 日前放出，许可证都没公布。

## 回到标题：能不能重燃国模荣光

模型这关，我认为过了——第三方榜单第 4、跑分咬住 Opus、单任务成本只有 Opus 的三分之一（AA 评测成本口径），这不是情怀分，是数据分。

但「荣光」是个比榜单更大的词。还差两个条件：一是 11 月 4 日权重真的落地、许可证真的开放，让「开源第一」从宣传语变成可验证的事实；二是把额度这本账算明白，别让「模型够得着 Opus、套餐先用不起」成为常态。

能力、开放、可持续三件事，能力这关算过了，另外两关还没交卷。答案也不用等太久：11 月 4 日的权重和接下来的套餐细则，会替 Kimi 把剩下两关的卷子交了。
