# 怎么看 Anthropic 发布称 AI agent 的工时是员工的 6 倍，初级技术岗位占比下降？

先说一件事：我刷到这条新闻的时候，心里咯噔了一下。

不是为我自己——我过去一年基本靠 AI 写代码，agent 越猛我越省劲。是为我刚入行那几年的自己。如果我是今年毕业的、只会把需求翻译成代码的初级程序员，看到「AI agent 工时是员工的 6 倍、初级岗占比腰斩」这种标题，今晚大概率睡不着。这半年来这类新闻一条接一条，焦虑不是抽象的，是具体到「我这个岗位三年后还在不在」的。<!-- 判断句 -->

但这份报告真正吓人的地方，其实不是 6 倍。

我去看了一眼报告原文（[主文](https://www.anthropic.com/research/expectations-for-the-future)和两份技术报告：[employment](https://www.anthropic.com/research/employment-at-anthropic)、[expectations gap](https://www.anthropic.com/research/ai-expectations-gap)，2026 年 10 月 16 日发布），里面藏着一对比 6 倍扎心得多的数字：**初级岗位占技术招聘的比例，从 27% 掉到了 9%。** 6 倍说的是 agent 多能干，这组数字说的是公司还要不要新人。其他的回答里也抛了这个矛盾——初级不招了，初级怎么升资深——但没人接住。这篇就接这个：初级岗的通道确实在收窄，那还在通道里、和准备进通道的人，到底该怎么办。

## 先把两个吓人的数字按回原文

建立信任只需要三十秒，因为我真的去读了原文。

「6 倍」的口径是：2026 年 8 月，员工一句一句指挥的交互式 agent 会话的运行时总和（推理加工具调用时间，单次超过 30 分钟的等待不算），对比全体员工按人头×每周 40 小时算出的账面工时。agent 不用吃饭睡觉，人做不到，这个比法天然就是 agent 占便宜的。还有几个限定点：只算员工直接指挥的交互式会话（自主跑的不在里面），交互式会话大约 80% 的时间是 agent 在等人回话，研究部门是 19 倍、其他部门远低于此。<!-- 判断句 -->

「初级岗下降」也有背景：这家公司一年内整体扩张了三倍，技术岗绝对规模在涨，初级员工占技术部门的比例从 21% 降到 14%，降的是占比，不是绝对数。<!-- 判断句 -->

口径讲完，不恋战。真正的问题是：就算把水分全挤掉，招聘占比 27%→9% 这个变化也是实打实的。接下来是这篇真正想讲的部分。

## 新人怎么办：四条我能站得住的判断

先交代我的视角：我写 Flutter，过去一年代码基本交给 AI 写，这个话题我上个月刚写过一篇[《AI 编程普及到底是替代程序员，还是把创造力平权给普通人？》](https://www.zhihu.com/question/2091803976455013001)，当时的判断是：被抽掉的是「把需求翻译成代码」的中间层，AI 替代的是执行、留下来的是验收。这份报告给我的感觉是——这个判断没错，只是招聘端动手比预想快得多。以下四条，是从报告数据和我自己的活里挤出来的。

**第一条：纯执行的翻译型工作，定价已经崩了，别再往这个方向攒资历。**

报告里有个数字很能说明问题：非技术员工用 coding agent 的频率，从 2025 年 8 月的每月 2 次涨到 2026 年 5 月的每月 90 次。运营、产品、职能岗的人自己写工具、自己查数据，不需要找程序员转一手了。<!-- 判断句 -->这和我旧稿里的观察是同一件事：「想到」和「做到」之间的沟被填平了大半，而初级程序员过去赖以为生的，恰恰就是站在沟里帮人搭桥这段活。这段活现在接近免费，靠它攒年限的路径大概率走不通了。<!-- 判断句 -->

**第二条：验收成了新的入场券，而验收恰恰需要代码功底——这是好消息，但门票变贵了。**

报告里，agent 写的代码被 revert（回滚）和删除的比例，跟手写代码没有可检测的差异。读原文要注意，报告自己标注了这个结论有自选择偏差：员工可能把简单任务交给 agent、难的自己写，如果这样，「无差异」会高估 AI 代码的真实质量。<!-- 判断句 -->

这个 caveat 的存在本身就是答案：为什么还需要人？因为「差不多对」和「真对」之间的那段距离，目前只有人会看。我在旧稿里引过 Stack Overflow 2025 年调查，66% 的开发者说 AI 方案「差不多对但不完全对」——判断 AI 产出对不对，需要知道正常情况长什么样，这就回到了写代码的基本功。<!-- 判断句 -->所以对新人来说，残酷的点在于：基本功不但没过时，反而成了定价的依据——只是计价方式从「按你写了多少行」换成了「按你能看出多少坑」。<!-- 判断句 -->

**第三条：出现了一个新型的初级岗位雏形——管 agent 的人，而这活儿现在正是初级能抢的。**

报告里有两组数字值得放在一起看：meta-work（管 agent 的协调类工作——拆任务、写指令、验收产出，听起来虚，说白了就是「当 agent 的包工头」）占会话的比例从 10% 涨到 22%；员工写给 agent 的书面常驻指令，从几百条涨到 8500 条。<!-- 判断句 -->

8500 条指令是什么概念？这是有人在对 agent 做持续的「岗前培训」和「规章制度建设」。报告里管这叫在练一种新技能，我的翻译更土一点：**这活儿没有资深不资深之分，它太新了，所有人都站在起跑线上，而新人对这类活的学习速度往往不比老人慢。**<!-- 判断句 -->公司里第一批能把「验收 + 管 agent」干出体系的人，大概率不会是从十年前的老经验里长出来的。对初级程序员，这可能是这轮变化里唯一的结构性机会窗口。<!-- 判断句 -->

**第四条：成长路径换了账本——从「写代码攒年限」变成「带 agent 攒判断」。**

老路径：写三年代码，踩够坑，升资深。新路径大概率是：带 agent 干足够多的活，攒下足够多的「这活儿 AI 会怎么搞砸」的预判。人均 commit 数是半年前的 5 倍，说明一个人带 agent 能同时推进的事多了好几倍——同样三年，经历的判断次数可能是过去的三到五倍。<!-- 判断句 -->从这个意义上说，初级变资深的梯子没有被抽走，换材料重造了：以前的梯级是代码行数，现在的梯级是你验收过多少、拦下过多少。<!-- 判断句 -->

我知道这四条听起来像「行业会变好」的安慰剂，所以最后必须把丑话讲清楚。

## 丑话：这份报告回答不了你的问题

这份报告是单一前沿实验室的样本，报告自己写了不能外推。Anthropic 是全球最激进用自己产品的 AI 公司，员工是全世界最会指挥 agent 的一群人，模型是它自己最新的。它的今天，大概率是 AI 行业的上限而不是均值。<!-- 判断句 -->

所以「初级岗 27%→9%」这个数，准确的读法是：**在最会用 agent 的一家公司里，扩张三倍的同时，招聘结构往资深一端大幅倾斜了。**它证明的是「这条通道在最激进的地方已经收窄」，证明不了「全行业初级岗都会消失」——反过来，「初级岗其实没事」这个安慰版本，同样没有任何数据支持。<!-- 判断句 -->

[图片：Anthropic expectations gap 报告中关于样本不可外推的 caveat 段落截图；应截取真实信源页面 https://www.anthropic.com/research/ai-expectations-gap，禁止编造]

对还在读的、刚入职的、工作三年的程序员，我能给的最诚实的建议只有一条：把「我会写代码」从简历的第一行挪下来，换上「我验收过多少真实业务代码、我带 agent 干成过什么事」——前者在快速贬值，后者刚刚定价。<!-- 判断句 -->

至于整个行业会不会走到 Anthropic 这一步，现在下任何结论都为时过早，包括乐观的那种。
