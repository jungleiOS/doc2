# 怎么看 Anthropic 发布称 AI agent 的工时是员工的 6 倍，初级技术岗位占比下降？

我刷到这条新闻的时候，心里咯噔了一下——不是为我自己，我过去一年基本靠 AI 写代码，agent 越猛我越省劲；是为今年毕业、只会把需求翻译成代码的初级程序员。这半年这类新闻一条接一条，焦虑是具体到「我这个岗位三年后还在不在」的。<!-- 判断句 -->

但这份报告真正吓人的地方，其实不是 6 倍。

我去看了一眼报告原文（[主文](https://www.anthropic.com/research/expectations-for-the-future)和两份技术报告：[employment](https://www.anthropic.com/research/employment-at-anthropic)、[expectations gap](https://www.anthropic.com/research/ai-expectations-gap)，2026 年 10 月 16 日发布），里面藏着一对比 6 倍扎心得多的数字：**初级岗位占技术招聘的比例，从 27% 掉到了 9%。** 6 倍说的是 agent 多能干，这组数字说的是公司还要不要新人。现有回答多在争论 6 倍的口径，少有人接住这组数字，这篇就接：通道确实在收窄，那还在通道里、和准备进通道的人，该怎么办。

## 先把两个吓人的数字按回原文

「6 倍」的口径是：2026 年 8 月，员工一句一句指挥的交互式 agent 会话的运行时总和（推理加工具调用，单次超过 30 分钟的等待不算），对比全体员工按人头×每周 40 小时算出的账面工时——agent 不用吃饭睡觉，人做不到，这个比法离「一个 agent 顶 6 个人」还很远。细分数据里研究部门据报道达 19 倍、其他部门远低于此，交互式会话大约 80% 的时间还是 agent 在等人回话。<!-- 判断句 -->

「初级岗下降」也有背景：据报道，这家公司一年内整体扩张了三倍，技术岗绝对规模在涨，初级员工占技术部门的比例自 2025 年初从 21% 降到 14%，降的是占比，不是绝对数。<!-- 判断句 -->

![Anthropic employment 报告 Figure 1：初级员工占技术部门比例降至 14%、初级岗位占技术招聘比例降至 9%（2025 年初以来）](https://h.uguu.se/SFJoomAW.png)

（图源：[How employment is changing at Anthropic](https://www.anthropic.com/research/employment-at-anthropic)，2026-10-16）

![Anthropic employment 报告 Figure 2：agent 工时与人类工时对比曲线，2026 年 3 月 agent 工时总量超过人类，8 月交互式会话达 6 倍](https://n.uguu.se/iOzfKGuz.png)

（图源：[How employment is changing at Anthropic](https://www.anthropic.com/research/employment-at-anthropic)，2026-10-16）

口径讲完，不恋战。就算把水分全挤掉，招聘占比 27%→9% 也是实打实的变化。接下来是这篇真正想讲的部分。

## 新人怎么办：四条我能站得住的判断

先交代我的视角：我写 Flutter，过去一年代码基本交给 AI 写，上个月刚写过一篇[《AI 编程普及到底是替代程序员，还是把创造力平权给普通人？》](https://www.zhihu.com/question/2091803976455013001)，当时的判断是：被抽掉的是「把需求翻译成代码」的中间层，AI 替代的是执行、留下来的是验收。这份报告告诉我：这个判断没错，只是招聘端动手比预想快得多。以下四条，是从报告数据和我自己的活里挤出来的。

**第一条：纯执行的翻译型工作，定价已经崩了，别再往这个方向攒资历。**

报告里有个数字很能说明问题：非技术员工用 coding agent 的频率，从 2025 年 8 月的每月 2 次涨到 2026 年 5 月的每月 90 次，运营、产品、职能岗的人自己写工具、自己查数据，不再需要找程序员转一手。<!-- 判断句 -->这和我旧稿里的观察是同一件事：「想到」和「做到」之间的沟被填平了大半，而初级程序员过去赖以为生的，恰恰就是站在沟里帮人搭桥这段活，这段活现在接近零边际成本，靠它攒年限大概率走不通了。<!-- 判断句 -->

**第二条：验收成了新的入场券，而验收恰恰需要代码功底——这是好消息，但门票变贵了。**

先把一个事实说透：报告里，agent 写的代码被 revert（回滚）和删除的比例，跟手写代码没有可检测的差异。这个「无差异」值得琢磨——它说明 AI 代码的平均水平已经不拖后腿了，拿平均水平吓唬人的时代过去了。<!-- 判断句 -->

真正的分水岭在另一头。报告在 revert 对比上挂了原话级的提醒：AI 犯的错误可能跟人不一样，而且**可能比人的错误更难识别**——这种错语法上完全成立、跑起来大部分时候也对，但埋的位置很刁钻，只有亲手写过这类代码的人，才看得出它埋在哪、为什么会炸。发现的成本在那 5% 里，而找出那 5%，需要写代码攒出来的直觉。<!-- 判断句 -->这跟这家公司招聘越来越看重 autonomy 和 judgment（自主性和判断力）而非产出速度的判断也对得上。<!-- 判断句 -->所以对新人来说，残酷的点在于：基本功不但没过时，反而成了定价的依据——只是计价方式从「按你写了多少行」换成了「按你能看出多少坑」。<!-- 判断句 -->

**第三条：出现了一个新型的初级岗位雏形——管 agent 的人，而这活儿对有基本功的新人格外友好。**

报告里有两组数字值得放在一起看：meta-work（管 agent 的协调类工作——拆任务、写指令、验收产出，听起来虚，说白了就是「当 agent 的包工头」）占会话的比例从 10% 涨到 22%；员工写给 agent 的书面常驻指令，从几百条涨到 8500 条。<!-- 判断句 -->

![报告原文关键句段落：写给 agent 的常驻书面指令从几百条增至 8500 条，meta-work 占交互式会话比例从 10%（2025 年秋）升至 22%（2026 年春）](https://h.uguu.se/PiheuYvZ.png)

（图源：[How employment is changing at Anthropic](https://www.anthropic.com/research/employment-at-anthropic)，2026-10-16）

8500 条指令是什么概念？有人在对 agent 做持续的「岗前培训」和「规章制度建设」。我的翻译更土一点：**这活儿没有资深不资深之分，它太新了，所有人都站在起跑线上**——但窗口不是对所有人开放的：管 agent 的前提是看得出 agent 干得对不对，这就回到了第二条的验收功底。对有代码基本功的新人，这类活的学习曲线大概率不比老人陡，这可能是这轮变化里对初级程序员最友好的一个机会窗口。<!-- 判断句 -->

还有几个容易被标题党略过的细节，方向上其实有利于「通道换形而非消失」：公司建立了岗位风险预警机制、优先内部转岗，司龄一年以上的老员工每月跨部门流动概率比 2025 年高 50%，报告还举了文案团队转岗去写 eval（评测）和 prompt 的例子——初级岗位在收拢，但公司没有把人扫地出门，更多是在往新的位置上搬。<!-- 判断句 -->

**第四条：成长路径换了账本——从「写代码攒年限」变成「带 agent 攒判断」，但别拿 commit 数自我感动。**

老路径：写三年代码，踩够坑，升资深。新路径大概率是：带 agent 干足够多的活，攒下足够多的「这活儿 AI 会怎么搞砸」的预判。报告里人均 commit 数是半年前的 5 倍，这里先泼半盆冷水：commit 多不等于产出同比例涨——The AI Corner 转述过一项覆盖 50 万 GitHub 开发者的研究（Demirer、Musolff、Yang 等人），用 agent 的开发者 commit 涨了 240%，release（真正发出去的版本）只涨了 30%，多出来的大量提交可能只是半成品和来回折腾。<!-- 判断句 -->

所以这个账本的立论，建议落在可自证的积累上：别数 commit，数你验收过多少、拦下过多少。你亲手拦下来的那个「AI 在这儿一定会翻车」的坑，写进简历比「人均 commit 翻了几倍」硬得多——前者是你的判断力，后者是 agent 的手速。<!-- 判断句 -->初级变资深的梯子大概率没被抽走，只是换了材料：以前的梯级是代码行数，现在的梯级是验收记录。<!-- 判断句 -->

这四条听起来像安慰剂，所以最后把丑话讲清楚。

## 丑话：这份报告回答不了你的问题

这份报告是单一前沿实验室的样本，报告自己提示了外推的风险——Anthropic 的员工是全世界最会指挥 agent 的一群人，模型是它自己最新的。它的今天未必是行业的均值，但作为领先指标仍有参考价值。<!-- 判断句 -->

所以「初级岗 27%→9%」这个数，准确的读法是：**在最会用 agent 的一家公司里，扩张三倍的同时，招聘结构往资深一端大幅倾斜了。**它证明的是「这条通道在最激进的地方已经收窄」，证明不了「全行业初级岗都会消失」；反过来，「初级岗其实没事」这个安慰版本，同样没有数据支持。<!-- 判断句 -->

![AI expectations gap 报告结论段的提醒：公众预期能漂移多远，取决于 AI 能否像在前沿实验室那样承担其他地方同样多的工作](https://h.uguu.se/SsQVSFPZ.png)

（图源：[The AI expectations gap](https://www.anthropic.com/research/ai-expectations-gap)，2026-10-16）

丑话讲完，给两句能落地的。在职的、工作三五年的：把「我会写代码」从简历第一行挪下来，换上你验收过多少真实业务代码、带 agent 干成过什么事——前者在快速贬值，后者刚刚定价。<!-- 判断句 -->还在读书、明年找工作的：现在就可以干一件具体的事——去给开源项目做 AI 产出的人工 review，或在个人项目里留一份「AI 写的 + 我改过什么、为什么」的记录，明年面试大概率比课程项目硬得多。<!-- 判断句 -->

至于整个行业会不会走到 Anthropic 这一步，现在下任何结论都为时过早，包括乐观的那种。
