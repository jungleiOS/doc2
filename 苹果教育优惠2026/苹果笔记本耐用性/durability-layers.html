Mac「耐用」的三层逻辑
每一层 Windows 都输一截，叠加起来差距就大了
01硬件
硬件本身能撑多久
MacBook
整块铝合金铣削外壳，无接缝无卡扣。Air 电池 500 次循环，Pro 1000 次循环至 80% 容量
同价位 Windows 本
大量塑料机身或塑料底壳。电池循环寿命多数 500 次，衰减速度因厂商而异
↓
02系统
系统能给你更新多久
macOS
更新支持周期约 7 年。2026 年 macOS Tahoe 支持至 2020 年机型。芯片+系统+驱动一家控
Windows
Windows 11 硬件门槛挡住 2018 年前电脑。驱动碎片化，OEM 老机型维护优先级靠后
↓
03保值
不想用了，能卖多少钱
MacBook Air M5
教育价 9249 入手，两年后二手 5500-6000。月成本 ¥135-156
同价位 Windows 本
同价 9000-9500 入手，两年后二手 3000-3500。月成本 ¥229-271

「用了好几年都不卡」不是魔法，是硬件扎实 + 系统有人管 + 卖掉不亏钱三件事叠加的结果。
Windows 本一年一小卡三年一大卡，卡的不是硬件，是系统生态的维护周期到了。
