# 考勤核算学习笔记 —— 从打卡记录到白班/加班统计

> 配套文件：`08月白班及加班统计.xlsx`（三个 sheet：汇总表 / 每日明细 / 口径说明）
> 本文讲清楚每个公式背后的知识点，看完你应该能自己改口径、自己排查问题。

## 一、核算口径（先用大白话讲规则）

1. **一天怎么算出勤**：当天既有首卡又有末卡，才算「正常」出勤 1 天。只有签到（单卡）、一张卡都没有（空卡），程序不猜，留白交给人补。
2. **当天干了多久**：末卡 − 首卡 = 在岗跨度。
3. **取整**：跨度四舍五入到 **0.5 小时**（30 分钟一格）。这是工厂计薪的常见粒度，7 月原表就是这么取的。
4. **白班封顶**：每天最多算 **12 小时白班**——`MIN(取整工时, 12)`。
5. **加班**：超出 12 的部分才算加班——`MAX(取整工时 − 12, 0)`。
6. 这套口径不是我拍脑袋定的，是**用 7 月已有人工统计表反推 + 验证**出来的（见第四节）。

## 二、每日明细的六个公式（Excel 版）

以第 2 行为例，理解一个就懂全部：

| 列 | 公式 | 干什么 |
|---|---|---|
| G 状态 | `=IF($E2="","空卡",IF($F2="","单卡","正常"))` | 没首卡→空卡；有首卡没末卡→单卡；都有→正常 |
| H 跨度(分钟) | `=IF($G2="正常",ROUND(($F2-$E2)*1440,0),"")` | 末卡−首卡，化成分钟并取整 |
| I 跨度(h) | `=IF($G2="正常",$H2/60,"")` | 分钟÷60，只是给人看的 |
| J 取整工时 | `=IF($G2="正常",ROUND($H2/30,0)/2,"")` | 四舍五入到 0.5 小时 |
| K 白班 | `=IF($G2="正常",MIN($J2,12),"")` | 封顶 12h |
| L 加班 | `=IF($G2="正常",MAX($J2-12,0),"")` | 超出部分 |

### 知识点 1：Excel 里的时间其实是数字

Excel 把一天存成 `1`，一小时是 `1/24`，一分钟是 `1/1440`。
所以 `末卡−首卡` 得到的不是「几小时」，而是「几分之几天」：

- `(F2-E2)*24` → 小时
- `(F2-E2)*1440` → 分钟（**我们的公式用这个**）

这也解释了为什么首卡末卡单元格显示 `06:58`，但可以做减法。

### 知识点 2：必须先化成分钟，再取整 —— 浮点数的坑

计算机用二进制存小数，很多十进制小数存不精确：

```
0.1 + 0.2 = 0.30000000000000004   （不是 0.3）
```

时间也一样：某员工 12 小时 15 分钟 = 44100 秒，计算机里

```
44100 ÷ 86400 × 24 = 12.249999999999998   （差一点才到 12.25）
```

如果直接 `ROUND((F2-E2)*24*2, 0)/2`，这个「差一点」会让本该进位的 12.5 被判成 12.0，**每人每次差 0.5 小时**。第一版公式就栽在这里（8 个人差 0.5h，校验抓出来的）。

**解法**：先 `ROUND((F2-E2)*1440, 0)` 得到**整数分钟**；整数 ÷30 在关键边界上是精确值（735÷30 = 24.5 在二进制里是精确的），再 ROUND 就稳了。

> 教训：**涉及「刚好卡线」的取整，先把数据化成整数单位**（分钟、分、元），再做判断。

### 知识点 3：ROUND 是四舍五入，FLOOR/CEILING 是砍/补

- `ROUND(24.5, 0)` = 25（四舍五入，.5 向上）
- `FLOOR(24.5, 1)` = 24（向下砍）
- `CEILING(24.5, 1)` = 25（向上补）

7 月数据里 13.48h 被记成 13.5h，证明原表用的是**四舍五入**而不是往下砍——这个区别值 0.5h/天，用错全表皆错。

### 知识点 4：MIN/MAX 是「封顶」和「保底」的通用写法

- `MIN(工时, 12)`：超过 12 按 12 算 → **封顶**
- `MAX(工时-12, 0)`：不够 12 时加班不出现负数 → **保底**

比写 `IF(工时>12, 12, 工时)` 简洁，且逻辑一目了然。

### 知识点 5：先取整再封顶，顺序不能反

`MIN(取整(12.26), 12)`：12.26 → 取整 **12.5** → 白班 12，加班 **0.5**
若先封顶：`取整(MIN(12.26, 12))`：12.26 → 12 → 白班 12，加班 **0**

同样 12.26 小时，加班差 0.5h。7 月原表的数字证明口径是**先取整、后封顶**。

## 三、汇总表的公式：COUNTIFS / SUMIFS

以左栏第 3 行为例（杨秀联）：

```
上班天数 B3 = IF(COUNTIFS(明细!$A$2:$A$1892,$A3,明细!$G$2:$G$1892,"正常")=0,"/",COUNTIFS(...))
白班     C3 = IF($B3="/","/",SUMIFS(明细!$K$2:$K$1892,明细!$A$2:$A$1892,$A3))
加班     D3 = IF($B3="/","/",SUMIFS(明细!$L$2:$L$1892,明细!$A$2:$A$1892,$A3))
合计     E3 = IF($B3="/","/",$C3+$D3)
```

### 知识点 6：COUNTIFS / SUMIFS 的语法

- `COUNTIFS(条件区1, 条件1, 条件区2, 条件2, ...)` —— 数出**同时满足**所有条件的行数
  - 这里：姓名=杨秀联 **且** 状态=正常 → 上班天数
- `SUMIFS(求和区, 条件区1, 条件1, ...)` —— 把满足条件的行**加起来**
  - 注意参数顺序和 COUNTIFS 相反：**求和区在最前面**
- 全月无出勤的人显示「/」而不是 0，和 7 月表的习惯一致。

### 知识点 7：`$` 绝对引用与跨表引用

- `$A$2:$A$1892`：`$` 锁住行列，公式向下填充时范围不跑。
- `明细!$K$2:$K$1892`：跨 sheet 引用，格式是 `表名!单元格`；表名含中文或空格时加引号 `'每日明细'!K2`。
- 汇总只引用明细，**不要手改汇总**——改明细，汇总自动重算。这是整个设计最重要的维护原则。

## 四、这套口径是怎么来的（方法论，可复用）

1. **拿到 7 月已有人工统计表当「标准答案」**（45 个有数据的人）。
2. **提出假设**：跨度取整 0.5h、白班封顶 12h、超出算加班。
3. **写程序批量复算并对照**：白班 40/45 完全吻合、加班 41/45 完全吻合、天数 44/45。
4. **不吻合的 5 人逐一看差额**：都是 ±2~6h 的手工调整痕迹（请假扣减、漏卡补登），不是规则错误——规则本身被验证为可信。
5. **边界探测**：用 13.48→13.5 确认是「四舍五入」而非「向下取整」；用先取整后封顶的数字差异确认计算顺序。

> 通用套路：**有历史答案就先反推规则，用样本验证到 90%+ 吻合才敢上线，不吻合的逐单查明原因。**

## 五、维护手册

| 需求 | 做法 |
|---|---|
| 补卡 | 在明细标黄行的首卡/末卡填入 `hh:mm`，全表自动重算 |
| 改封顶（如白班改 11.5h） | 改明细 K 列 `MIN(J2,12)`→`MIN(J2,11.5)`，L 列 `MAX(J2-12,0)`→`MAX(J2-11.5,0)`，选中两格双击填充柄下拉 |
| 改取整粒度（如 15 分钟） | J 列改 `ROUND($H2/15,0)/4`（15 分钟 = 1/4 小时） |
| 加新人 | 明细底部加 31 行（可复制前一个人的行），汇总加一个姓名行，复制公式 |
| 换月份 | 直接改日期列与首末卡数据即可 |
